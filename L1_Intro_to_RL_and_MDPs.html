Part 1

What is Reinforcement Learning?

Learning what to do — how to map situations to actions — so as to maximise a numerical reward signal.

Three ways to learn from data

What makes RL different?

1🎯

Only a reward, no teacher

Supervised: told the correct answer.

RL: told only how good the outcome was, a single number.

2⏳

Feedback is delayed

Supervised: feedback on every example, immediately.

RL: win or lose at the end: which of my 50 moves deserves the credit?

3🔗

Data comes in a sequence

Supervised: shuffled, independent examples (i.i.d.).

RL: each observation depends on the one before. Time matters.

4🕹️

The agent's actions shape its own data

RL: what you do decides what you get to see next. Explore badly and you never discover the good parts. This is the exploration vs exploitation dilemma.

5🗺️

No rule book: learn by interacting

RL: nobody gives the agent the physics or the rules of the game. It must learn them implicitly, by trial and error.

RL = learning to act, by trial and error, from delayed, evaluative feedback.

A familiar example: training a cat

🐱

🛋️

The agent–environment loop

At each step $t$: agent observes $\est{S_t}$, takes $\est{A_t}$; environment returns reward $\rew{R_{t+1}}$ and next state $\nxt{S_{t+1}}$.  Trajectory: $S_0, A_0, R_1, S_1, A_1, R_2, \dots$

Rewards

Reward

A reward $R_t$ is a scalar feedback signal: how well is the agent doing at step $t$?

Reward hypothesis

All goals can be described by the maximisation of expected cumulative reward.

  • Win a game: +1 win, −1 loss
  • Balance an inverted pendulum: +1 per step upright
  • Reach design luminosity in a collider: + luminosity

Warning: the agent optimises exactly what you reward — not what you meant. We return to reward hacking in Lecture 2.

Sequential decision making

  • Goal: select actions to maximise total future reward
  • Actions have long-term consequences
  • Reward may be delayed
  • It may be better to sacrifice immediate reward for more long-term reward (investments, blocking an opponent)

History and state

The history is everything observed so far:

$H_t = O_1, R_1, A_1, \; O_2, R_2, A_2, \; \dots, \; A_{t-1}, O_t, R_t$

The state is a summary of history used to decide what happens next: $\;S_t = f(H_t)$

Game

Pixels on screen (maybe several frames)

Helicopter / drone

Position, orientation, velocities

Chess

Position of all pieces (+ castling rights…)

Environment observability

Fully observable: $O_t = S_t$ (→ MDP).   Partially observable: agent sees only part of it (→ POMDP): robot camera, trading agent, poker.

The Markov property

“The future is independent of the past given the present.”

Definition

A state $S_t$ is Markov if and only if   $\mathbb{P}[S_{t+1} \mid S_t] = \mathbb{P}[S_{t+1} \mid S_1, \dots, S_t]$

Part 2

From Markov chains to reward processes

Build the formalism one layer at a time: $\langle S, P\rangle \to \langle S, P, R, \gamma\rangle \to \langle S, A, P, R, \gamma\rangle$

Markov process (Markov chain)

Definition

A Markov process is a tuple $\langle \mathcal{S}, \mathcal{P} \rangle$: a memoryless random sequence $S_1, S_2, \dots$ with the Markov property.

  • $\mathcal{S}$ — a (finite) set of states
  • $\mathcal{P}$ — a state transition probability matrix

Transition probability: $\quad \mathcal{P}_{ss'} = \mathbb{P}\left[S_{t+1} = s' \mid S_t = s\right]$

$\mathcal{P} = \begin{bmatrix} \mathcal{P}_{11} & \cdots & \mathcal{P}_{1n} \\ \vdots & \ddots & \vdots \\ \mathcal{P}_{n1} & \cdots & \mathcal{P}_{nn}\end{bmatrix}$

row = "from", column = "to"
each row sums to 1

Example: the Student Markov chain

…and its transition matrix

Markov reward process

Definition

A Markov reward process is a Markov chain with values: $\langle \mathcal{S}, \mathcal{P}, \mathcal{R}, \gamma \rangle$

  • $\mathcal{S}$ — finite set of states
  • $\mathcal{P}$ — transition matrix
  • $\mathcal{R}$ — reward function,
    $\mathcal{R}_s = \mathbb{E}\left[R_{t+1} \mid S_t = s\right]$
  • $\gamma \in [0, 1]$ — discount factor

Return and discount

Return

The return $G_t$ is the total discounted reward from time-step $t$: $\quad \rew{G_t} = \rew{R_{t+1}} + \gamma \rew{R_{t+2}} + \gamma^2 \rew{R_{t+3}} + \dots = \sum_{k=0}^{\infty} \gamma^k \rew{R_{t+k+1}}$

$\gamma \to 0$: “myopic” — only immediate reward matters.   $\gamma \to 1$: “far-sighted”.

Why discount?

  • Mathematically convenient: keeps returns finite in cyclic processes
  • Uncertainty about the future may not be fully represented in the model
  • Financial rewards: money now earns interest
  • Animal & human behaviour prefers immediate reward

Undiscounted ($\gamma = 1$)?

Fine if all sequences are guaranteed to terminate (episodic tasks).

In practice $\gamma$ is also a hyperparameter: it trades bias (short horizon) against variance and learning difficulty.

Value function

Definition

The state value function $v(s)$ of an MRP is the expected return starting from state $s$:

$\est{v(s)} = \mathbb{E}\left[\,\rew{G_t} \mid S_t = s\,\right]$
  • The return $G_t$ is random (a different episode each time)
  • The value $v(s)$ is its average — a number per state: long-term desirability
  • Simplest estimate: sample many episodes and average the returns → Monte-Carlo (next slide, and Lecture 2)

The Bellman equation for MRPs

value being definedreward (real experience)value of the next state

The value function decomposes into two parts:

  • immediate reward $\rew{R_{t+1}}$
  • discounted value of the successor state $\gamma\, \nxt{v(S_{t+1})}$
$\begin{aligned} \est{v(s)} &= \mathbb{E}\left[\rew{G_t} \mid S_t = s\right] \\ &= \mathbb{E}\left[\rew{R_{t+1}} + \gamma \rew{R_{t+2}} + \gamma^2 \rew{R_{t+3}} + \dots \mid S_t = s\right] \\ &= \mathbb{E}\left[\rew{R_{t+1}} + \gamma\,(\rew{R_{t+2}} + \gamma \rew{R_{t+3}} + \dots) \mid S_t = s\right] \\ &= \mathbb{E}\left[\rew{R_{t+1}} + \gamma\, \rew{G_{t+1}} \mid S_t = s\right] \\ &= \mathbb{E}\left[\rew{R_{t+1}} + \gamma\, \nxt{v(S_{t+1})} \mid S_t = s\right] \end{aligned}$
$\est{v(s)} = \rew{\mathcal{R}_s} + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}_{ss'}\, \nxt{v(s')}$

one-step look-ahead: value = reward now + discounted average value next

Bellman equation in matrix form

$\est{\mathbf{v}} = \rew{\mathcal{R}} + \gamma\, \mathcal{P}\, \nxt{\mathbf{v}}$
$\est{\begin{bmatrix} v(1) \\ \vdots \\ v(n)\end{bmatrix}} = \rew{\begin{bmatrix} \mathcal{R}_1 \\ \vdots \\ \mathcal{R}_n\end{bmatrix}} + \gamma \begin{bmatrix} \mathcal{P}_{11} & \cdots & \mathcal{P}_{1n} \\ \vdots & & \vdots \\ \mathcal{P}_{n1} & \cdots & \mathcal{P}_{nn}\end{bmatrix} \nxt{\begin{bmatrix} v(1) \\ \vdots \\ v(n)\end{bmatrix}}$

It's linear → solve directly

$\mathbf{v} = (I - \gamma \mathcal{P})^{-1} \mathcal{R}$
  • cost $O(n^3)$ for $n$ states → only small MRPs
  • Large problems: iterative methods
    • Dynamic programming
    • Monte-Carlo evaluation
    • Temporal-Difference learning

Or: just apply the Bellman equation repeatedly

Part 3

Markov Decision Processes

Now the agent gets to choose.

Markov decision process

Definition

A Markov decision process is an MRP with decisions: $\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$

  • $\mathcal{S}$ — finite set of states  ·  $\mathcal{A}$ — finite set of actions
  • $\mathcal{P}^a_{ss'} = \mathbb{P}\left[S_{t+1} = s' \mid S_t = s, A_t = a\right]$ — transitions now depend on the action
  • $\mathcal{R}^a_s = \mathbb{E}\left[R_{t+1} \mid S_t = s, A_t = a\right]$
  • $\gamma \in [0,1]$
  • Almost all RL problems can be formalised as MDPs (optimal control = continuous MDPs; POMDPs can be converted)
  • Transitions may still be stochastic: the same action can lead to different next states

Example: the Student MDP

Policies

Definition

A policy $\pi$ is a distribution over actions given states:   $\pi(a \mid s) = \mathbb{P}\left[A_t = a \mid S_t = s\right]$

  • A policy fully defines the behaviour of an agent
  • MDP policies depend only on the current state (not the history) → stationary
  • Stochastic: in state $s$ take $a_1$ w.p. 0.8, $a_2$ w.p. 0.2  ·  Deterministic: $a = \pi(s)$

Given an MDP and a fixed policy $\pi$, the process reduces to an MRP $\langle \mathcal{S}, \mathcal{P}^\pi, \mathcal{R}^\pi, \gamma \rangle$ with $\;\mathcal{P}^\pi_{ss'} = \sum_{a} \pi(a|s)\, \mathcal{P}^a_{ss'}\;$ and $\;\mathcal{R}^\pi_s = \sum_a \pi(a|s)\, \mathcal{R}^a_s$ — so everything from Part 2 applies!

Value functions of an MDP

State-value function

$v_\pi(s)$: expected return starting from $s$, then following $\pi$

$\est{v_\pi(s)} = \mathbb{E}_\pi\left[\,\rew{G_t} \mid S_t = s\,\right]$
Action-value function

$q_\pi(s,a)$: expected return starting from $s$, taking action $a$, then following $\pi$

$\est{q_\pi(s, a)} = \mathbb{E}_\pi\left[\,\rew{G_t} \mid S_t = s, A_t = a\,\right]$

$q$ answers “how good is this action here?” — the quantity Q-learning and DQN learn directly.

$v_\pi$ for the Student MDP — you choose $\pi$

Bellman expectation equations

Same decomposition: immediate reward + discounted value of the successor:

$\est{v_\pi(s)} = \mathbb{E}_\pi\left[\rew{R_{t+1}} + \gamma\, \nxt{v_\pi(S_{t+1})} \mid S_t = s\right]$
$\est{q_\pi(s,a)} = \mathbb{E}_\pi\left[\rew{R_{t+1}} + \gamma\, \nxt{q_\pi(S_{t+1}, A_{t+1})} \mid S_t = s, A_t = a\right]$

$v$ from $q$ — average over the agent's choice

$\est{v_\pi(s)} = \sum_{a} \pi(a|s)\, q_\pi(s,a)$

$q$ from $v$ — average over the environment

$\est{q_\pi(s,a)} = \rew{\mathcal{R}^a_s} + \gamma \sum_{s'} \mathcal{P}^a_{ss'}\, \nxt{v_\pi(s')}$

Backup diagrams: two averages stacked

$\est{v_\pi(s)} = \sum_{a} \pi(a|s) \left( \rew{\mathcal{R}^a_s} + \gamma \sum_{s'} \mathcal{P}^a_{ss'}\, \nxt{v_\pi(s')} \right) \qquad \est{q_\pi(s,a)} = \rew{\mathcal{R}^a_s} + \gamma \sum_{s'} \mathcal{P}^a_{ss'} \sum_{a'} \pi(a'|s')\, \nxt{q_\pi(s',a')}$

Your turn

Uniform random policy, $\gamma = 1$. Given $v_\pi(\text{C1}) = -1.3$, $v_\pi(\text{C2}) = 2.7$, $v_\pi(\text{C3}) = 7.4$, verify $v_\pi(\text{C3})$:

$\begin{aligned} v_\pi(\text{C3}) &= 0.5\,\underbrace{(10)}_{\text{Study}} + 0.5\,\underbrace{\big(1 + 0.2(-1.3) + 0.4(2.7) + 0.4(7.4)\big)}_{\text{Pub}} \\ &= 5 + 0.5\,(4.78) = 7.39 \approx 7.4 \;\checkmark \end{aligned}$

Bellman expectation equation holds — and it holds for every state simultaneously. That's a linear system: $\mathbf{v}_\pi = (I - \gamma\mathcal{P}^\pi)^{-1}\mathcal{R}^\pi$.

Optimal value functions

Definition

The optimal state-value function is the maximum over all policies: $\quad v_*(s) = \max_\pi v_\pi(s)$

The optimal action-value function: $\quad q_*(s,a) = \max_\pi q_\pi(s,a)$

  • $v_*$ specifies the best possible performance in the MDP
  • An MDP is “solved” when we know the optimal value function

Optimal values for the Student MDP

Optimal policy

Partial ordering:   $\pi \geq \pi' \;\text{ if }\; v_\pi(s) \geq v_{\pi'}(s),\; \forall s$

Theorem — for any MDP
  • There exists an optimal policy $\pi_*$ that is better than or equal to all other policies
  • All optimal policies achieve $v_{\pi_*}(s) = v_*(s)$ and $q_{\pi_*}(s,a) = q_*(s,a)$

If we know $q_*$, we're done

$\pi_*(a|s) = \begin{cases} 1 & \text{if } a = \arg\max_{a \in \mathcal{A}} q_*(s,a) \\ 0 & \text{otherwise}\end{cases}$

There is always a deterministic optimal policy. No model needed to act: just take the argmax.

Bellman optimality equations

$\est{v_*(s)} = \max_a \left( \rew{\mathcal{R}^a_s} + \gamma \sum_{s'} \mathcal{P}^a_{ss'}\, \nxt{v_*(s')} \right)$
$\est{q_*(s,a)} = \rew{\mathcal{R}^a_s} + \gamma \sum_{s'} \mathcal{P}^a_{ss'} \nxt{\max_{a'} q_*(s', a')}$

Instead of averaging over the agent's actions, take the max. The environment's randomness is still averaged.

Solving the Bellman optimality equation

  • The max makes it non-linear → no closed-form solution in general
  • Many iterative solution methods:

Know the model $\mathcal{P}, \mathcal{R}$? → Planning

Value iteration · Policy iteration (dynamic programming)

Only have experience? → RL

Monte-Carlo · SARSA · Q-learning · DQN · policy gradients

The rest of the course is, essentially, clever ways of solving the Bellman equations when the state space is huge and the model is unknown.
