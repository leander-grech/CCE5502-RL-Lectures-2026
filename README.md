# CCE5502 · Reinforcement Learning — lectures (2026)

Interactive lecture slides for **CCE5502 – Fundamentals of AI and ML** (University of Malta), by Dr Leander Grech.

**Open the slides:** https://leander-grech.github.io/CCE5502-RL-Lectures-2026/

| Deck | Contents |
|---|---|
| [Lecture 1 — Intro to RL & MDPs](https://leander-grech.github.io/CCE5502-RL-Lectures-2026/L1_Intro_to_RL_and_MDPs.html) | Agent–environment loop, Markov property, MRPs, MDPs, Bellman equations |
| [Lecture 2 — RL algorithms](https://leander-grech.github.io/CCE5502-RL-Lectures-2026/L2_RL_Algorithms.html) | DP, MC vs TD, SARSA/Q-learning, DQN + CartPole, policy gradients/PPO, reward hacking |

PDFs of each deck are in [`pdf/`](pdf/). The 2025 slides are kept in [`archive/2025/`](archive/2025/).

## Using the slides

Everything runs in the browser with no build step and no internet needed (KaTeX and fonts are bundled), so you can also clone the repo and open `index.html` locally.

→ / Space: next · ←: previous · O: overview · G ⟨n⟩ Enter: go to slide · F: fullscreen · M: mind map · I: back to index · ?: all shortcuts
